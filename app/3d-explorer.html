Adding profiles / names (manual)
New ICC profile? Drop the .icc / .icm into icc/ then run python scripts/gen_luts.py AND python scripts/gen_libraries.py, then refresh.

New Japanese / HTML name? Edit data/corpora/name_corpora.json. Append an entry ({"name": "桜色", "romaji": "sakura-iro", "hex": "#FCC9D2"} for jpn, {"name": "rose", "hex": "#FF007F"} for html), save, refresh. No Python rebuild needed — Lab is computed in browser.
