cmyk · swatch tools

Pick colors that survive the press.

Two small browser tools for designing with CMYK against real ICC profiles. Explore live, or browse a curated library that has already passed a round-trip safety filter.

01 · live

CMYK Explorer

A grid of every CMYK value at your chosen step, rendered through the ICC profile you pick. Compare presses, find named colors, build palettes.

open
02 · curated

3D Swatch Explorer

A pre-filtered library of print-safe colors per profile, generated offline with a round-trip ΔE gate. Sort by hue, lightness, or safety.

open

What the tools share

Both run as static HTML. Both load the same per-profile lookup tables produced by the Python toolchain in scripts/. Both export palettes as ASE, GPL, PNG, and JSON. Palettes saved in one tool import cleanly into the other.

No telemetry. No backend. The color math is real, the profile choices are explicit, the data is on disk.

How it works

Add CMYK ICC profiles to icc/, run python scripts/gen_luts.py to build the lookup tables and python scripts/gen_libraries.py to produce the curated library. Open index.html over a local HTTP server. ICCs are not committed to the repo; bring your own.
