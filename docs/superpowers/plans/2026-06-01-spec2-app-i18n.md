# Spec 2 Implementation Plan · App tri-lingual i18n

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the proven landing-page tri-lingual pattern (EN / 日本語 / 繁中) into `app/cmyk-explorer.html` and `app/3d-explorer.html`. Hybrid storage: inline `data-en/ja/zh` for static UI text, JS `I18N` string table for dynamic strings, `data-title-en/ja/zh` attributes for native `title` tooltips. Topbar segmented switch. Per-page localStorage keys. Browser language detection with EN fallback.

**Architecture:** Same i18n primitives in both apps, dropped into the existing markup + script. Static labels wrap content in three sibling spans gated by `html[lang]` CSS. Tooltips use parallel attribute triples swapped into the live `title` attribute on language change. Dynamic count / alert / empty-state strings flow through a `t(key, vars)` helper backed by a JS string table. The topbar switch fires a single `applyLang()` routine that updates the lang attribute, button highlights, every tooltip, and re-emits all dynamic strings.

**Tech Stack:** Vanilla HTML / CSS / JS. No external i18n library. No additional fetches. Strings ship inside the HTMLs.

**Reference spec:** `docs/superpowers/specs/2026-06-01-app-i18n-design.md`

**Pre-requisite:** Spec 3 Section 3 (tooltip layman rewrite) must land first. Otherwise this plan translates jargon. If Spec 3 Section 3 has not yet landed when this plan starts, pause and run Spec 3 Section 3 first.

// ── Spec 2: tri-lingual i18n primitives ─────────────────────────────────
const I18N_KEY = 'mixoLangCmyk_v1';
const VALID_LANGS = new Set(['en', 'ja', 'zh']);
let ACTIVE_LANG = 'en';

function detectLang() {
  let stored = null;
  try { stored = localStorage.getItem(I18N_KEY); } catch {}
  if (VALID_LANGS.has(stored)) return stored;
  const langs = (navigator.languages && navigator.languages.length)
    ? navigator.languages : [navigator.language || 'en'];
  for (const raw of langs) {
    const tag = String(raw).toLowerCase();
    if (tag.startsWith('ja')) return 'ja';
    if (tag.startsWith('zh')) return 'zh';
    if (tag.startsWith('en')) return 'en';
  }
  return 'en';
}

function applyLang(lang) {
  if (!VALID_LANGS.has(lang)) lang = 'en';
  ACTIVE_LANG = lang;
  document.documentElement.setAttribute('lang', lang);
  document.querySelectorAll('#langSwitch button').forEach(b =>
    b.classList.toggle('on', b.dataset.lang === lang));
  document.querySelectorAll('[data-title-en]').forEach(el => {
    const v = el.getAttribute('data-title-' + lang) || el.getAttribute('data-title-en');
    if (v) el.setAttribute('title', v);
  });
  try { localStorage.setItem(I18N_KEY, lang); } catch {}
  if (typeof render === 'function') render();
}
